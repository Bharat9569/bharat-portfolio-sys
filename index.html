How I Build With AI

AI speeds up the build, but I stay in charge of the engineering.

  1. Idea
    Define the problem and who it's for
  2. Prompt / Spec
    Architecture, requirements, expected behavior
  3. AI Coding Agent
    Codex, Claude or Cursor works from the spec
  4. Implementation
    Generated code reviewed and shaped by me
  5. Test & Debug
    Verify behavior, trace and fix issues
  6. Iterate
    Refine the spec and the code in tight loops
  7. Deploy
    Ship to real users and monitor
